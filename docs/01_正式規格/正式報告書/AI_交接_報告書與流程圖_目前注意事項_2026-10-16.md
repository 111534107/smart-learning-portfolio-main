## 5. 目前要注意的事

### 5.1 給組員

1. **打開 Word 檔時**如果跳出「是否更新功能變數」，按「是」。目錄頁碼才會正確。
2. **改了內文後**要在 Word 裡對目錄按右鍵 →「更新功能變數」→「更新整個目錄」，圖目錄也要做一次。
3. **簡報的小字**：學生主線、系統架構、總體流程、三張 ERD 的圖比較大，放進投影片後字偏小。投影前要決定是否拆成兩頁或放大局部。
4. **封面日期**是原檔的「中華民國 116 年 06 月」，沒有改；如需更改請自行修改封面。

### 5.2 給接手的 AI

1. **流程圖要修改時**：改 `docs\images\` 的 `.mmd`，再用 Mermaid CLI 重出 PNG／SVG：
   `mmdc -i 檔名.mmd -o 檔名.png -b white -s 2`（有 SVG 的也要重出）。
   - 使用案例圖（圖 1～4）是用 `D-01-use-case-by-role.py` 產生，改那支程式再執行。
   - ERD 是用 `D-09-erd-build.py` 產生，改程式裡的欄位後執行，再重出四張圖。
2. **改了圖之後**：報告書 Markdown 與 Word 直接引用圖檔，要重新產生 Word；簡報要把新圖換進對應投影片（工具見第 6 節）。
3. **還有舊說法的圖**：圖 9 科辦電子獎狀中「科辦找指導老師」是描述現行人工流程，刻意保留，不是系統角色。
4. **Word 自動化卡住時**（`word_update.ps1` 超過 10 分鐘沒反應）：用工作管理員或 PowerShell 查 `WINWORD.EXE`，命令列含 `/Automation -Embedding` 的是程式開的，可以結束；沒有這個參數的是使用者自己開的，不要關，請使用者關。檔案被佔用時先請使用者關掉 Word。
5. **`docs\images\` 裡的 `*-readable.png`** 是其他代理留下、尚未提交的舊版圖，這次沒有更新，不要拿來用。

## 6. 重新產生檔案的工具

工具放在 `工具\`（從 Claude 的暫存區複製過來，路徑寫死在 `D:\democase\ai\docs\...`）：

| 工具 | 用途 | 注意 |
| --- | --- | --- |
| `build_versions.py` | 從 `報告書內容.md` 產生完整版／精簡版 Markdown 與兩份簡報 | 目標檔已存在就會停下，不覆蓋；要重產請先改輸出檔名 |
| `build_docx.py` | 以原 Word 封面＋精簡版內容產生正式 Word | 同上，目標檔存在會停下 |
| `word_update.ps1` | 用 Word 更新目錄、圖目錄頁碼並轉 PDF | 需要電腦裝有 Word |
| `pdf2png.ps1` | PDF 逐頁轉圖片，用來檢查排版 | 用 Windows 內建 PDF 功能 |
| `ppt_export.ps1` | 簡報逐頁匯出圖片，用來檢查排版 | 需要電腦裝有 PowerPoint |
| `linkcheck.py` | 檢查 Markdown 相對連結是否失效 | 用法：`python linkcheck.py 資料夾` |

Python 用專案虛擬環境：`D:\democase\ai\.venv\Scripts\python.exe`。
