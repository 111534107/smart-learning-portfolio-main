## 一、為什麼做

二技招生資料已經由招生資料 Agent 抓下來、管理員核准，但核准後**沒有人會知道**：學生、導師、科辦都得自己去翻招生時程頁。UC-25 要讓「管理員核准 → 大家收到公告 → 導師提醒自己的四、五年級學生 → 科辦在寄送備審截止前把電子獎狀處理完」變成一條連起來的流程。

| 只有站內公告與提醒，不寄信、不推播 | 10-10 |

## 三、目標與不做

**做**
1. 管理員核准一組招生日程後，在同一個畫面看到**系統擬好的公告**（標題、內容、重要日期），可以修改文字後發布；也可以手動新增一則公告。
2. 學生、導師、科辦都有「二技公告」清單與內容頁；未讀的有標記，導覽列的「通知」數字會加一。
3. 導師在公告內容頁下方看到自己班上四、五年級學生（年級、目標校系數），按「提醒這些學生」→ 每位學生收到一則站內通知，寫進 `audit_logs`。
4. 科辦首頁多一張數字卡「二技截止前未核准的電子獎狀 N 件」，卡上寫截止日（例如「寄送備審 4/24 截止」），連到電子獎狀清單。
5. 公告可以下架（不能刪），下架後學生、老師、科辦看不到，管理員看得到並留紀錄。

**不做（這次）**
- AI 推薦校系、目標校系 5 所上限（10-10 規格第五節、3.2 節，另案）。
- 讓人手動輸入或修改截止日期。
- 一般（非二技）公告的畫面；資料表支援，但沒有入口。
- 電子郵件、手機推播。

**失敗的樣子（就算功能能跑也算做錯）**
- 科辦或管理員得手動填日期才看得到截止提醒。
- 學生看到還沒核准的候選資料。
- 導師看得到別班或一～三年級的學生。
- 為了公告未讀另外做一套和現有「通知」不一樣的鈴鐺。

## 四、怎麼接現有程式（盤點結果）

| 現有 | 用法 |
| --- | --- |
| `AdmissionScheduleEvent`（channel、學年度、項目、起訖、出處；candidate → published） + `admin.agent_schedule_decide` | 核准日程後，導到「擬公告」頁，內容由該組日程自動帶入。 |
| `admission_schedule.load_schedule()`（已核准的 Agent 日程優先，沒有時用 `app/content/admission_schedule.csv`） | 讀截止日。找名稱含「寄送備審」的項目，取結束時間（沒有結束時間用開始時間）。 |
| `Notification`（11-08 已改成 `case_id`、`event_id` 可空，有 `link`） | 發布公告時替每位收件人建一則通知（連到公告內容頁）；導師提醒也用它。導覽列的「通知」數字不用改。 |
| `teacher_scope.students_for_teacher()` + `journey_service.current_grade()` | 導師的學生，再篩四、五年級。 |
| `AwardCertificate.status == "pending"` | 科辦卡片的數字。 |
| `AuditLog` | 發布、下架、導師提醒都記。 |

## 七、截止提醒的規則

- 截止日 = 最近一則**已發布**二技公告對應管道、學年度的「寄送備審」項目結束時間。
- 今天還沒過截止日 → 顯示數字卡與日期；截止已過或沒有已發布公告 → 不顯示這張卡。
- 抓不到「寄送備審」項目 → 卡片照樣顯示數字，日期寫「簡章未載明」。

## 八、留給開發者決定的（我的判斷，非使用者決定）

- 未讀用 `announcement_reads`＋`Notification` 雙寫，而不是新做鈴鐺。
- 截止日讀 `load_schedule()`：Agent 核准的日程優先，沒有時才用既有 CSV（CSV 是從官方簡章整理的種子資料，不是新增人工輸入）。
- 截止卡「從何時開始顯示」= 有已發布公告就顯示，到截止日當天結束為止。
- 發布時只通知在職、啟用中的帳號；之後新增的帳號在清單裡仍看得到公告（未讀）。
- 同一組日程重複核准時，草稿會重新產生，不會自動再發一次公告。

## 九、驗收

1. 核准日程後看到預填的公告草稿；改字後發布，學生、導師、科辦清單都有這則且標未讀，導覽列「通知」數字增加；讀過後未讀消失。
2. 學生看不到草稿或已下架的公告；公告沒有刪除按鈕，下架寫進 `audit_logs`。
3. 導師只看到自己班四、五年級學生；按提醒後學生的通知出現老師的提醒，`audit_logs` 有紀錄。
4. 科辦首頁顯示「二技截止前未核准的電子獎狀 N 件」與寄送備審日期；日程裡沒有寄送備審時寫「簡章未載明」；截止過後卡片消失。
5. 沒有任何畫面讓人輸入截止日期。
6. 完整 pytest 通過；瀏覽器用合成資料走一次：管理員發布 → 三種角色看到未讀 → 科辦看到截止提醒。
