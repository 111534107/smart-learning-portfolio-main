# 學校 Google 登入

學生可以用學校 Google 帳號登入既有的學生帳號，沿用學號與學習歷程。管理員在帳號管理頁輸入學號，系統固定補上 `@stu.ukn.edu.tw`，且學號須與既有學生帳號一致。此入口不自行建立帳號，也不接受教師或管理員角色。

登入採伺服器端 OAuth 授權碼流程。登入頁只有設定好 Google OAuth 用戶端、密鑰與專用重新導向網址時顯示按鈕。發起登入時保存隨機 state；回呼時先驗證 state，再向 Google 換取 ID token。伺服器驗證簽章、簽發者、目標用戶端、有效期及 email_verified，並要求 ID token 的 email 恰為綁定的 `@stu.ukn.edu.tw` 信箱；Google Workspace 的 hd 可以是該子網域或學校主網域 `ukn.edu.tw`。

首次登入以經驗證的信箱找唯一既有學生帳號，並記錄 Google 的穩定 sub。之後以 sub 查找，仍核對綁定信箱、角色、啟用狀態及網域。管理員更換信箱時清除舊 sub。驗證失敗不建立登入工作階段，畫面只顯示一般錯誤。成功後沿用原本學生登入紀錄、歡迎流程與安全的 next 跳轉。

Google 登入與目前 Google 文件、Google 雲端硬碟的授權彼此獨立，使用專用回呼網址。原本帳密登入保留。專案提供設定說明與資料庫遷移；正式上線須在 Google Cloud 建立 OAuth 網頁用戶端並填入本機 `.env`，金鑰不進版控。
