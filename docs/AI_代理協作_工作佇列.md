此文件是 Codex、IDE 內的 BMAD Agent 與人工審閱者共用的交接點，目的在於避免重複貼上長篇上下文。

2. BMB 先讀取本文件，選擇唯一一項「待執行」工作，改為「進行中」。
3. 完成後，在本文件最下方追加代理回報，並將工作改為「待使用者確認」或「完成」。

此佇列不會自動喚醒 IDE 的 BMAD；它減少的是上下文複製，不取代使用者啟動 Agent 的動作。
