# 備審與履歷產出改版設計（待使用者確認）

> 狀態：設計草案，**尚未實作**。依據：使用者 2026-11-04 提供的參考資料（`docs/02_需求與設計/04_原始資料與參考/參考資料/`，含真實個資，不提交 Git、不送外部 AI）、各校備審準備指引的共通重點、以及系統現況。
> 使用者原話：「我很好奇為何我的系統生成履歷和自傳會這麼不像我需要的」「都要生成了，不如順便一起生成，到時候學生又增加新的證照又要再改寫自傳，所以可能還要再新增一鍵更新自傳」「學校給的格式不錯你參考一下」。

## 一、為什麼現在產出不像學生要的

| 原因 | 說明 |
| --- | --- |
| 資料太少 | 經歷只有「標題＋描述」，沒有「我負責什麼、數字成果、學到什麼」；範例最好的段落都靠這些細節（例如 49 台主機部署、10 米網路線搶修、50 張數位學習證書）。 |
| 沒有系所特色 | 範例會引用系的定位（例如「商業智慧化」「醫護＋教學設計＋數位學習」）並把同一段經歷換角度寫；系統沒有系所特色資料。 |
| 提示詞太死 | 固定 4 段、固定標題、600～900 字、不准寫感受；範例每份 2200～2600 字、標題依學校命名、有個人反思。 |
| 只有自傳、沒有策略與目錄 | 範例先寫「策略重點」（依加權決定先放哪些硬實力），再出「客製目錄」（每章列具體佐證）；系統的備審目錄只列類別。 |
| 輸出版面 | 學校的實習履歷格式是「封面＋一頁履歷表＋自傳＋成績單＋證照／競賽圖片格＋缺曠表」；系統的 Word 是文字清單。 |

## 二、要做的四件事

### A. 學校格式的「履歷／備審」Word（參考康寧資管科實習申請履歷）

固定頁序：
1. 封面：校名、科名、文件名稱（實習申請履歷／二技備審資料）、學號、姓名、期間或目標校系。
2. 一頁履歷表（表格）：基本資料＋照片（用學期照片）；已修習專業核心科目（科目＋學分，三欄）；操行平均成績；相關證照（依發證單位分「勞動部／國際／國內／其他」）；語文能力（英、日、台、客 × 精通／中等／略懂）。
3. 自傳（見 B）。
4. 成績單（學生上傳的成績單原檔）。
5. 證照：兩欄圖片格，每格下方寫名稱。
6. 競賽：兩欄圖片格，寫比賽名稱、屆次、名次。
7. 缺曠紀錄：只放合計表（只給本人與班導，**不送外部 AI**，專題 `AGENTS.md` §8）。

系統已有：成績與學分、證照、競賽經歷、佐證圖片、學期照片、缺曠合計。
需要新增：語文能力、操行等第（學生填、導師可確認）。地址、電話、出生日期、身分證：**不存系統**，匯出時讓學生在 Word 自己填（只留空白欄）。

### B. 自傳：統一版＋核心優勢＋各校客製

1. **核心優勢盤點**（統一版）：從已確認資料整理學生的 4～6 項核心優勢，以及一張**分類統計表**（例如國家技術士證 3 張、國際認證 3 張、競賽獲獎 N 項）。
2. **統一自傳**：不針對學校，可用在實習、一般申請；保留學生口吻與反思。
3. **各校客製自傳**（每個目標校系一份，沿用 11/2 決定）：
   - 先產出「策略重點」：依該校加權決定哪些硬實力先放、篇幅比例。
   - 依系所特色把同一段經歷換角度寫；段落標題依內容命名；長度依簡章規定（沒有規定時約 1500～2500 字）。
   - 防止編造的規則保留：只能用學生已確認的資料與回答；每段標出引用來源。
4. **客製目錄**：依加權排章節，每章列出對應的具體佐證（例如「3.1 電腦硬體裝修丙級」）。

### C. 一鍵更新自傳

- 學生新增或修改並確認資料（證照、競賽、經歷、成績）後，所有用到舊資料的自傳、目錄標示「**資料已更新，可重新產生**」，並列出新增了哪些資料。
- 「一鍵更新」：統一版與所有目標校系一次重新產生；**舊版本保留**（版本紀錄不可刪），學生改過的段落先列出差異讓學生選擇保留或採用新版，不直接覆蓋。
- 有 Google 文件的校系，提示學生先「從 Google 文件取回」再更新，避免兩邊不一致。
- AI 次數：一鍵更新會用掉多次 AI 額度，畫面先顯示「這次會用掉 N 次」。

### D. 讓 AI 有東西可寫

1. **經歷欄位結構化**：新增「我負責的部分」「數字成果」「學到什麼」「相關領域標籤（例如醫療資訊、數位學習、系統開發）」；新增經歷時用引導問題，一次一題。
2. **系所特色資料**：升學 Agent 上網找各系官方網站與備審指引時，一併擷取「系所定位、課程重點、看重的能力」，成為候選資料，管理員核准後供自傳使用。
3. **4 題問題補強**：依備審指引加上「原本的狀態」「為了這個系做了哪些準備」「團體作品中你負責什麼」。
4. **示範資料**：換成有細節的假資料（標示「僅為測試資料」），展示才看得出效果。

## 三、建議順序

1. D-1 經歷結構化＋D-4 示範資料（沒有資料，後面都做不好）
2. B 自傳改版（統一版、核心優勢、各校客製、客製目錄）
3. A 學校格式 Word
4. C 一鍵更新
5. D-2 系所特色（接在升學 Agent 上網搜尋之後）
