2. **不要推送、不要合併進 `main` 或 `release/*`、不要 `git push --force`、不要改寫歷史**，除非真人在對話裡明確說「推到某某網址」；推送一律用完整網址，推前掃金鑰。
3. **不要刪檔、不要清理他人的未提交修改**：開工先 `git status`，有不是你造成的修改先問真人。
4. **不要讀、不要提交 `.env`**（內含金鑰）；測試只用假資料，不要寫入真實姓名、學號、帳密。

8. **AI 功能的底線**：AI 只給建議、人按接受才生效；不得新增學生沒寫過的經歷、數字、獎項、證照；缺曠資料不送外部 AI；送外部 AI 前遮蔽姓名、學號。

10. **每次修改寫開發日誌**（`docs/03_開發紀錄/development-log.md` 最上面追加一節）並只提交自己改的檔案；日誌與文件一律正體中文。
11. **不確定就問真人**，不要自己猜、不要自己決定要不要推送、合併、刪除或重啟公開展示站。
