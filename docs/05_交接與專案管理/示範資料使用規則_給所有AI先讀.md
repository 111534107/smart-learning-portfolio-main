# 示範資料使用規則（所有 AI 開工前先讀）

使用者放的**真實格式示範資料**在 `docs/OCR測試資料/`。測試上傳、辨認、確認、畢業門檻、獎懲匯入、實習履歷時，**先用這個資料夾的檔案實際跑一次**，不要自己生成假檔案或假成績當作驗收。自己生成的資料只能用來建帳號、補測試案例，不能取代這些檔案。

## 使用方式
1. 用內建瀏覽器開展示站，登入示範學生（密碼都是 `demo1234`），從上傳頁選上表的檔案，走完「上傳 → 辨認 → 確認 → 看畢業門檻／我的檔案」。
2. 自動化測試要用真檔案時，用 `analyze_document("transcript", 檔案路徑, "rapidocr")`；一般單元測試仍用假物件，不連外部服務（AGENTS 第 7 節）。
3. 驗收結果和上表不一樣，就是回歸，要在開發日誌寫明。

## 注意（個資）
- 這些檔案含真實姓名與學號格式的資料，屬使用者提供的測試用途；**不得**送到外部 AI，不得貼到對話或報告投影片，截圖要遮蔽。
- 新增示範檔案時，在上表補一列。
