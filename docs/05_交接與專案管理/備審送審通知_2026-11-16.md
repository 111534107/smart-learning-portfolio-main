# 備審送審通知工作清單

- [x] 學生送審及更新送審時，通知其班級中每位啟用的導師，通知連到該筆備審。
- [x] 導師確認或要求修改時，通知學生並連到校系的導師確認區。
- [x] 檢查多位導師、重複班級指派、未啟用老師、通知權限、已讀及重複操作。
- [x] 無啟用中的班級導師時，提醒學生聯絡管理員。
- [x] 學生取消目標校系後仍可開啟自己的當次審核結果，其他人無法查看。
- [x] 執行備審通知及相關導師流程測試（23 項通過）。
- [ ] 在展示版用學生與導師帳號操作並確認顯示。
- [ ] 確認班級指派的學年度與權限規則後，檢查歷年導師應否接收通知。
- [ ] 使用者確認後，再依指示推送個人 GitHub。
