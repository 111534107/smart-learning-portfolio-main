# Copilot 圖標桌寵修改說明

## 做法
- 批次生成頁移除自訂白色小人角色與原 `.batch-pet-*` 漫遊層，只保留既有的 `.assistant__toggle` 圓形圖標。
- 生成期間依目前輪詢到的 `running` 校系捲動並移動圖標至 A4 紙張右上角旁，完成後依序顯示 Ciallo 泡泡；全部完成後還原圖標位置並停留完成泡泡。
- 圖標施法期間攔截點擊，並提供魔法棒、星星、肌肉手臂及表情外觀；失敗、完成與待命都有對應泡泡與表情。
-沿用既有批次啟動、輪詢、重試與引導題連結流程，未修改 Python。
- 已補齊標楷體白紙黑字、生成中淡灰占位線、完成章、375px 手機版與減少動態設定。

## 第二輪修正
- 將批次生成前端拆成「後端輪詢狀態」與「呈現佇列」：輪詢只更新各校後端狀態，A4 紙張依原校系順序逐張播放移動、施法、蓋章與泡泡；即使後端瞬間回報全部完成，也會為每所學校保留至少約 2.6 秒的呈現時間。
- 每張紙分為移動到紙旁約 0.8 秒、施法與星星約 1.4 秒、完成蓋章加「Ciallo～(∠・ω<)⌒★」泡泡約 0.4 秒以上的節奏；後端仍在處理時停留施法狀態等待，不提前進入下一校或完成畫面。
- 全部呈現佇列播完且後端確認各校完成後，才顯示「資管小助手很高興為你服務」與完成區塊，再把圖標移回原本右下角位置。
- 初始及等待中的 A4 紙強制維持白底、黑字與標楷體，淡灰色佔位線條不受深色主題影響；等待中文字統一為「等待小助手」。
- 每所開始呈現時確認 `.assistant__toggle` 位於紙張右上角附近：紙張不在畫面內會以 `scrollIntoView({ block: 'center' })` 捲至中央，再依紙張 `getBoundingClientRect()` 設定固定定位的 left/top；保持 prefers-reduced-motion 行為，且不新增套件、不修改 Python。

## 第三輪修正
- 桌寵泡泡改以圖標實際位置計算固定定位，水平座標夾在 12px 與「視窗寬度減 12px 再減泡泡寬度」之間；泡泡最大寬度為 `min(280px, calc(100vw - 24px))`，文字自動換行。
- 圖標位於視窗右側時泡泡靠右對齊，位於左側時靠左對齊；上方空間不足時改放圖標下方。泡泡層級高於圖標本身，表情層級完整可見。
- 泡泡在顯示約 3 秒後只縮回桌寵圖標；視窗尺寸或捲動時重新夾限泡泡位置，並保留 prefers-reduced-motion 行為。
- 啟動後進度看板的按鈕改為「小助手施法中」並 disabled，說明改為「正在依序生成，請保持頁面開啟」；全部完成後隱藏開始按鈕與說明，只保留完成訊息與進度條。

## 第四輪：顏文字
- 批次頁 52px 圓形圖標改用顏文字：待命「(・ω・)」、施法「(｀・ω・´)」、單校完成「(≧▽≦)」、失敗「(；´Д｀)」、全部完成「ヽ(>∀<☆)ノ」；使用 `var(--fs-xs)`、負字距、單行與置中，並縮放較長表情避免超出圓形。
- 施法期間以 CSS 定位及動畫在圖標左右顯示「ᕦ」與「ᕤ」，沿用魔法棒效果，星星與原泡泡文案不變；設定 CJK／符號字型並為手臂優先使用 Segoe UI Symbol。
- 遵循 prefers-reduced-motion 與頁面 reduced-motion 設定：停用動畫並隱藏施法裝飾，只切換顏文字；未新增套件或修改 Python。
