# Copilot 過關修正第一輪

## 修改結果

1. 寫自傳頁的 `.canva-toolbar` 改為文件流，不再黏住或固定；並在每個 `.draft__paragraph` 內新增段落工具列，包含上一段、段落位置與使用既有表單的儲存按鈕。
2. 實習履歷頁的 `.rz-bar` 改為一般文件流工具列。手機與平板小於 1100px 時，`.rz-side` 與把手改為一般區塊，預設收合、點把手展開；電腦版維持右側欄。
3. 學生首頁手機版導覽邀請改為頁面中的一般區塊，不再使用 fixed。
4. 批次生成泡泡維持 fixed，但限制在可視寬度內並設定換行與橫向溢出裁切，降低泡泡造成 A1 捲動的風險。
5. 小於 1100px 時，頁首品牌連結、導覽連結、帳號按鈕、通知鈕及導師工作台篩選／排序控制加入至少 44px 可點高度。
6. 小於 1100px 時，所有摺疊標題加入 flex 置中與至少 44px 高度；目標校系、畢業門檻、五年資料夾等展開列也納入修正。
7. 我的資料分頁、五年資料夾、導覽按鈕、畢業門檻展開列、字級切換及實習履歷輸入框／選單等既有小控件，在手機與平板設為至少 44px 可點高度。
8. 畢業門檻警示文字改用既有深色警示變數，在淺色與深色外觀都維持較高對比。
9. 寫自傳深色外觀的段落字數與「主張」標籤改用既有深色／淺色文字變數，不再固定為低對比淺色。
10. 首頁「你在這裡」、資料夾計數與導覽標示調整為既有主要文字／背景變數；實習履歷生成自傳按鈕文字改用既有前景色變數。
11. 畢業門檻整體進度與寫自傳段落標題改為可換行並允許溢出正常顯示，長標題不再被單行裁切。
12. 實習履歷的自由撰寫與每個參考段落 textarea 正上方新增位於文件流的「儲存草稿」按鈕，沿用既有表單的 `name="action"` 與 `value="save"`。
