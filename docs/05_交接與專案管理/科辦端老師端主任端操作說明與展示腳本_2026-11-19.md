# 科辦端、老師端、科主任端：操作說明與展示腳本（2026-11-19）

給不熟這三個角色的組員。每個角色一頁：登入、看得到什麼、能做什麼、不能做什麼，最後附 3 分鐘展示順序。

科辦與老師共用「教職員登入」。登入角色目前只有 `staff`（科辦）與 `teacher`（導師），科助與科主任都是 `staff`，靠**職稱**區分（主任、副主任＝科主任；科助、其他行政人員＝科助）。判斷集中在 `app/services/staff_roles.py`。報告時可以說「科助與科主任是各自獨立的使用者、權限不同」，實作是同一登入角色加職稱（若老師問，這是刻意先不拆登入角色的取捨）。

## 一、科助（`staff01`）

**看得到**：科辦工作台（待核准獎狀）、電子獎狀、表單下載區、年級總覽、自己的操作紀錄。
**能做**：
1. 電子獎狀：審核內文、建立、批量開立、退回。**科助建立的獎狀是「待核准」**，學生還看不到、也沒有驗證碼。
2. 表單下載區：手動上架表單、檢查連結；從學校網站更新表單（代理會建立「待核准上架」的新表單）。
3. 年級總覽：看專一到專五的成績、證照、獎項、上傳檔統計（只算學生已確認的資料）。
**不能做**：核准獎狀、核准表單上架、指派導師班級、看別人的操作紀錄。進這些頁面或按這些按鈕會被擋（403 或提示「要由主任或副主任按」）。
**展示順序（約 3 分鐘）**：登入 → 工作台 → 電子獎狀「批量開立」建立幾張 → 回列表看到狀態是「待核准」→ 操作紀錄只看得到自己 → 試著開 `/staff/classes` 被擋。

## 二、科主任（`chief01`，職稱主任或副主任）

**科助能做的全部都能做，另外**：
1. **核准電子獎狀**：在「電子獎狀核准」勾選科助建立的待核准獎狀，**一次核准多張**；核准後才有驗證碼、學生才收到通知。主任自己建立的獎狀直接核准。
2. **核准表單上架**：代理或科助上架的新表單要主任或副主任核准學生與老師才看得到；也能重新上架。
3. **導師班級指派**（本次新增，導覽列「導師班級」，網址 `/staff/classes`）：決定哪位導師帶哪個班。可選學年度、同班可有多位導師、同一位導師同班同學年度重複新增會被擋、新增與移除都寫操作紀錄；管理員頁 `/admin/classes` 保留作系統維護。
4. **操作紀錄看全科辦**：可依人篩選，只列動作與對象、不列內容。
**展示順序（約 3 分鐘）**：登入 → 電子獎狀核准頁勾選、一次核准（接續科助展示）→ 學生端看到獎狀通知與驗證碼 → 導師班級：新增 `teacher01` 帶某班、再新增同一筆被擋 → 操作紀錄看到全部人的動作 → 說明「科助做不到這些」。

## 三、導師（`teacher01`）

**只看得到自己帶班級的學生**（`teacher_scope.can_view_student`）；用網址硬開別班學生會被擋（403）。
**導師工作台**（`/teacher/dashboard`）：畢業門檻提醒（全班概況）、本班學生清單（可切換班級）、哪些學生有待確認的備審、各校系準備進度、班級摘要（只傳匿名統計，少於 5 人留在本機，不外送）。
**學生頁**（點學生進去），上方「快速查看」可跳到：
- 資料狀態與五年資料（草稿、已確認、狀態待確認，依年級分）、佐證照片
- 畢業門檻（學分與證照缺口、檢核倒數、學期預警）
- 目標校系與備審／自傳（每個校系的準備度、缺什麼）
- 實習履歷（本次新增，唯讀：學生最後一次儲存或下載的內容）
**能做**：
1. **確認備審**：學生送審時系統存一份快照，導師確認的是那一份；選「確認」或「需要修改」（要寫建議）；按錯可撤回並寫原因。
2. **自傳**：預設收合，要不要看由導師決定；確認時可勾「我已查看自傳」（沒勾就記為「未檢視自傳」，學生會看到「導師已確認（已檢視／未檢視自傳）」）；不看也不擋任何流程。可替自傳段落加註解、修改文字（存成新的一版，舊版保留）。送審後自傳又存了新版時，不能確認舊的那份，只能請學生重新送審。
3. 提醒學生補資料（針對某個目標校系）、看通知。
**不能做**：看別班學生、改學生的成績與證照資料、核准獎狀、指派班級。
**展示順序（約 3 分鐘）**：先用 `113534903` 送審一個校系 → 換 `teacher01` 登入 → 工作台看到待確認 → 進學生頁「快速查看」依序點畢業門檻、目標校系、實習履歷 → 展開自傳、勾「我已查看自傳」後確認 → 回學生端看到「導師已確認（已檢視自傳）」。

## 五、老師可能問的幾個問題

- **科主任與科助是不是各自獨立的使用者？** 是。權限不同（上表）；登入角色先用職稱區分，要拆成兩種登入角色只需改 `staff_roles.py` 與帳號建立，已留好位置。
- **導師由誰決定帶哪個班？** 科主任在「導師班級」決定，管理員保留系統維護入口；所有異動寫操作紀錄。
- **導師一定要看自傳嗎？** 不用。看與不看都可以確認，系統只記錄「有沒有看」，不存自傳全文。
- **導師看得到畢業門檻嗎？** 看得到：學分與證照缺口、檢核倒數、學期預警；正式畢業資格審查是教務處的事（頁面有說明）。
- **畢業後原導師還能看嗎？** 目前導師權限依班級名稱判斷、尚未依學年度限縮，是已知限制，待向老師確認。
- **這跟初審單不一樣？** 初審單是「審查委員評分」平台；現在是「學習歷程與備審準備」：學生準備、導師確認、科辦管獎狀與表單、科主任核准與指派。審查委員評分已拿掉（2026-10-10 決定）。
