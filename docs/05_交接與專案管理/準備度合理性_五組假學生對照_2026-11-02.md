# 準備度輸出合理性 假學生人工核算與系統對照

日期：2026-11-02。**本文件所有學生、校系與資料皆僅為測試資料。**

## 測試方式與依據

在記憶體 SQLite 建立同一個假校系與五個互相獨立的假學生，不連外部 AI、不使用真實個資。假校系三項權重分別為成績 40%、證照 30%、競賽 30%，對應類別已確認，權重合計 100%。

按目前系統的建議值規則先人工計算：已確認成績 90 分對應完成度 100%，80 分對應 75%；已確認證照與競賽各 1 筆對應 50%、2 筆對應 100%；沒有已確認資料為 0%。每項貢獻＝權重×該項完成度；三項相加為總準備度。這些是**系統自訂的示範規則**，不是校方正式評分，也不是錄取機率。例子沒有自傳、專題或無法對應的項目，不能據此宣稱所有情境皆合理。
