# Google 雲端硬碟設定步驟（使用者照做版）

日期：2026-11-18（台灣時間）｜撰寫：Claude｜分支 `feat/cloud-drive-finish`（工作目錄 `D:\democase\_worktrees\ai-wt-cloud-drive`）

> 這份是**要你本人動手**的部分：登入 Google、建立用戶端、把金鑰放進 `.env`。Claude 不能代替你登入或輸入密碼。
> **金鑰只放 `.env`**：不要提交、不要貼在對話、不要寫進任何文件或截圖。測試只用合成資料（僅為測試資料），不要上傳真實成績單。

## 先知道這個功能怎麼運作（1 分鐘）

- 用 **OAuth（管理員按按鈕授權）**，不用服務帳戶。原因：服務帳戶沒有自己的雲端硬碟空間，個人帳號測試不能用；OAuth 只要 `drive.file` 權限，系統只看得到自己建立的檔案。
- 檔案會放在你授權的那個 Google 帳號的雲端硬碟：`智慧學習歷程系統上傳檔／<學號>_<姓名>／成績單與證照｜經歷佐證｜自傳`。
- 權杖只放伺服器記憶體，**網站重開後要再按一次「連上 Google 雲端硬碟」**。
- 任何一步沒設好，新上傳的檔案自動存本機，畫面不會壞。

## 第 0 步：準備

- 一個要拿來測試的 Google 帳號（個人 Gmail 即可；正式導入改學校 Workspace）。
- 預計用的網址：`http://localhost:5185`（這份文件都用 5185 舉例；換埠號時下面每個 5185 都要一起換）。

## 第 1 步：建立（或沿用）Google Cloud 專案

1. 打開 <https://console.cloud.google.com/>，右上角確認登入的是第 0 步的帳號。
2. 畫面**左上角 Google Cloud 標誌右邊**的專案下拉選單 → 彈出視窗**右上角**「新增專案」。
3. 專案名稱填 `smart-learning-portfolio-demo`（之前做過自傳 Google 文件的話，直接選那個專案，跳到第 2 步）→「建立」。
4. 建好後再按一次左上角專案選單，確認目前選的是這個專案。

## 第 2 步：啟用 Google Drive API

1. 左上角「☰」選單 →「API 和服務」→「程式庫」。
2. 中間搜尋框輸入 `Google Drive API` → 點結果卡片 → 藍色「啟用」按鈕。
3. 看到「API 已啟用」頁面就完成。（沒做這步，測試連線會顯示「還沒啟用 Google Drive API」。）

## 第 3 步：設定 OAuth 同意畫面（Google Auth Platform）

1. 左上角「☰」→「API 和服務」→「OAuth 同意畫面」（新版會帶你到「Google Auth Platform」）。
2. 第一次進來按「開始」：
   - **應用程式資訊**：名稱填 `資管科智慧學習歷程系統（測試）`，使用者支援電子郵件選你的信箱。
   - **目標對象**：選「**外部**」。
   - **聯絡資訊**：填你的信箱 → 勾同意政策 →「建立」。
3. 左邊選單「**目標對象**」→ 確認發布狀態是「**測試中**」→ 下方「測試使用者」按「+ Add users」→ 加入第 0 步的帳號 →「儲存」。
   （沒加會出現「存取遭拒」，或測試連線顯示權限不足。）
4. 左邊選單「**資料存取**」→「新增或移除範圍」→ 右側面板搜尋 `drive.file` → 勾 `.../auth/drive.file`（說明是「查看、編輯、建立及刪除您透過這個應用程式使用的 Google 雲端硬碟檔案」）→ 面板最下面「更新」→ 頁面最下面「Save」。
   **不要**勾 `drive`（完整雲端硬碟）。

## 第 4 步：建立 OAuth 用戶端

1. 左邊選單「**用戶端**」→ 上方「+ 建立用戶端」。
2. 應用程式類型選「**網頁應用程式**」，名稱填 `slp-local-5185`。
3. 「已授權的重新導向 URI」按「+ 新增 URI」，**一字不差**貼上：
   ```
   http://localhost:5185/admin/storage/google/callback
   ```
   （之後要用別的埠號，就再多加一行對應的網址。用 `127.0.0.1` 開網站的話也要另外加 `127.0.0.1` 版本。）
4. 按「建立」→ 彈出視窗會顯示「用戶端 ID」與「用戶端密鑰」。
   - 按旁邊的複製圖示，**直接貼到下一步的 `.env`**，不要貼到聊天或文件。
   - 之前做過自傳 Google 文件、已經有用戶端的話：打開那個用戶端，只要在第 3 點多加一行重新導向網址並「儲存」，ID 和密鑰沿用。

## 第 5 步：把設定放進 `.env`

1. 在檔案總管打開 `D:\democase\_worktrees\ai-wt-cloud-drive\`，新增檔案 `.env`（已在 `.gitignore`，不會被提交）。
   以後合併進主線，再把同樣幾行加進 `D:\democase\ai\.env`。
2. 用記事本貼上下面四行，把括號換成第 4 步複製的值（前後不要留空白）：
   ```
   STORAGE_BACKEND=google_drive
   GOOGLE_OAUTH_CLIENT_ID=（用戶端 ID，結尾是 .apps.googleusercontent.com）
   GOOGLE_OAUTH_CLIENT_SECRET=（用戶端密鑰）
   GOOGLE_STORAGE_REDIRECT_URI=http://localhost:5185/admin/storage/google/callback
   ```
3. 存檔（編碼 UTF-8）。

## 第 6 步：啟動網站並連線

1. 開 PowerShell，執行（不會碰公開展示站 5097）：
   ```powershell
   cd D:\democase\_worktrees\ai-wt-cloud-drive; $env:DEMO_PORT=5185; D:\democase\ai\.venv\Scripts\python.exe scripts\run_demo.py
   ```
2. 瀏覽器打開 `http://localhost:5185`（**要用 localhost，和第 4 步的網址一致**），用管理者 `admin` 登入（密碼見啟動視窗）。
3. 上方選單「檔案存放設定」：
   - 「.env 設定檢查」四項都要是綠色「正確」；有紅色「要處理」就照旁邊說明改 `.env`，改完重開網站。
   - 按「連上 Google 雲端硬碟」→ 選第 0 步的帳號 → 看到「Google 尚未驗證這個應用程式」按左下「繼續」→ 勾選雲端硬碟權限 →「繼續」。
   - 回到設定頁顯示「目前存在：Google 雲端硬碟」。
4. 按「**測試連線**」：下方應出現「連線正常」，四步都是「通過」，並顯示連上的帳號與空間用量。

| 測試連線顯示 | 代表 | 怎麼處理 |
|---|---|---|
| 不認得這組用戶端 ID 或密鑰 | ID／密鑰貼錯或不是同一個用戶端 | 回第 4 步重新複製，改 `.env` 後重開 |
| 重新導向網址不一致 | Google Cloud 登記的和 `.env` 不同 | 兩邊改成一字不差，網站也用同一個網址開 |
| 還沒啟用 Google Drive API | 第 2 步沒做或剛做完 | 啟用後等 2–5 分鐘再測 |
| 權限不足 | 沒加 drive.file 或帳號不在測試使用者 | 回第 3 步，之後重新連線 |
| 授權已過期或被撤銷 | 網站重開過或在 Google 帳號移除了授權 | 再按一次「連上 Google 雲端硬碟」 |
| 空間已滿 | 帳號雲端硬碟用到 95% 以上 | 清空間或換帳號 |

## 第 7 步：做完告訴 Claude，一起實測

做到第 6 步「連線正常」後，在對話說一聲（**不要貼任何金鑰**）。Claude 會在同一個網站用合成學生實測並把結果寫進日誌：

1. 學生上傳合成成績單 → 雲端「智慧學習歷程系統上傳檔／<學號>_<姓名>／成績單與證照」出現檔案。
2. 學生產生／儲存一版自傳 → 「自傳」子資料夾出現 Word 備份，自傳頁顯示「已備份到學校雲端」。
3. 備審一鍵打包 → 下載的壓縮檔內容正確（打包讀的是雲端檔的本機快取）。
4. 刪除一個佐證 → 雲端檔案**還在**，只多了刪除標記（M10：不實體刪除）。

你在雲端硬碟網頁上可以自己看到第 1、2、4 步的檔案。

## 第 8 步（要你決定）：舊檔要不要搬進學生資料夾

「檔案存放設定」→「看哪些舊檔可以搬」：

1. **預覽**：列出每位學生還在本機的成績單、證照、佐證、自傳備份，哪些找不到、哪些已標記刪除。只讀。
2. **試跑**：把可搬的檔案讀一遍、算雜湊、列出會放到雲端哪個資料夾。不連 Google、不改資料。
3. **真的搬**：輸入「確定搬移」才執行。檔案複製到雲端、資料庫改記雲端位置；**本機原檔保留不刪**，旁邊多一個 `.migrated.json`；已標記刪除的不搬；失敗的留在本機，可以再按一次。

建議：展示站的假資料每次啟動都會重建，**不必搬**；正式導入時先在測試機試跑，確認數量正確再搬。這一步由你決定，Claude 不會自己按。

## 停用與移除

1. `.env` 把 `STORAGE_BACKEND` 改回 `local`（或刪掉那四行）並重開網站：新上傳的檔案改存本機。
2. 「檔案存放設定」按「中斷 Google 雲端硬碟」清掉記憶體裡的權杖。
3. <https://myaccount.google.com/permissions> 移除本系統的存取權。
4. Google Cloud 刪除用戶端或整個專案；雲端硬碟裡的「智慧學習歷程系統上傳檔」資料夾可自行刪除（只有不再需要那些檔案時）。
5. 本次沒有安裝任何新套件，不需要額外移除。
