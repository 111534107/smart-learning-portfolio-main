# 同學試用回饋（推薦排序與「怎麼進這所學校」）

> 目的：使用者擔心其他同學對升學頁有不同想法。11/4 前找 3～5 位同學各試 10 分鐘，回饋帶去跟導師報告；新點子列為後續，不在 11/4 前硬做。
> 試用的是展示站假資料（僅為測試資料），不要讓同學輸入真實個資。

## 準備

1. 在 `D:\democase\ai-wt-story` 啟動展示站：`$env:DEMO_PORT=5032; D:\democase\ai\.venv\Scripts\python.exe scripts\run_demo.py`
2. 瀏覽 `http://127.0.0.1:5032/login`，按「王小明」快速登入。
3. 手機試用：在電腦瀏覽器按 F12 切換成手機寬度，或讓同學用自己的手機連同一個區網（需另外設定，可略過）。

## 操作路線（請同學自己操作，你只看、不提示）

1. 從首頁找到「推薦排序」。
2. 找一間你自己真的想讀的學校（可以用搜尋）。
3. 點進去，說說看「要上這間，你接下來會先做什麼」。
4. 切到「插大」看看。

## 問題（每位同學都問這 5 題）

1. 你找得到想讀的學校嗎？花了多久？
2. 點進學校後，看得懂「你差在哪」嗎？哪裡看不懂？
3. 看完知道下一步要做什麼嗎？
4. 你最希望這頁多告訴你什麼？
5. 哪裡讓你卡住或想放棄？
