## 合成配音影片

1. 組員的原始錄音放進 `錄音\`（不會被修改）。哪個檔案的第幾秒到第幾秒屬於哪一段，寫在 `合成影片.py` 的 `SECTIONS`；程式會切成 10 段放在 `錄音\分段\`。
2. 字幕會用語音辨識對到實際開口的時間；每段畫面長度配合錄音（操作畫面加快播放），不留空白。
3. 執行：

   ```
   D:\democase\ai\.venv\Scripts\python.exe "D:\democase\ai\docs\08_簡報\NAPAI初賽_最終繳交\合成影片.py"
   ```

4. 錄音還沒到齊時，輸出檔名會是「預覽_缺 N 段_…mp4」；全部到齊才會輸出正式檔名。每段音量會自動統一。
5. 語音辨識工具在 `D:\democase\ai\.tools\whisper\`（faster-whisper＋small 模型，約 750 MB）。
