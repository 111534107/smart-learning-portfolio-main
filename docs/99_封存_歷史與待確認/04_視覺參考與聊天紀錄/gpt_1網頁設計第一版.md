
喔——這批圖一放上來，我就比較確定你喜歡的其實**不是一般「漂亮的 UI」**。你喜歡的是「資訊本身就是視覺構圖」：路徑、資料夾、堆疊、人物、節點、空間感，把抽象資訊變成一幅可以探索的畫面。

而且這個方向跟「五年學習歷程」非常合。

我先不要急著定色票，因為你說後面還有很多。現在先把這 10 張裡值得偷師的「設計語言」拆出來。

## 我從這批圖看到了 5 個很明顯的共同點

**第一個是「路徑感」。**
你傳的藍線時間軸、日系 Worker 路線圖、Customer Journey 都不是傳統一格一格的表格，而是讓眼睛**沿著一條路走**。

這個我認為可以直接變成你們網站最重要的視覺語言：

> 專一 → 專二 → 專三 → 專四 → 專五 → 升學／實習／就業

而且不是一條死板直線。

可以像你第 4、8、10 張那樣有轉彎、分岔、節點、停靠站。

---

**第二個是「把抽象資料變成實體」。**

這點超適合資管。

你傳的圖不是寫：

> 文件很多。

而是直接給你看**一整片資料夾**。

不是寫：

> 層級很多。

而是把資料真的**一層一層疊起來**。

不是寫：

> 有不同工作階段。

而是讓人物真的「走過去」。

所以我們可以把：

「課程」→ 一本／一張資料頁
「作品」→ 文件卡
「證照」→ 徽章或票券
「學年」→ 一個區域
「目標校系」→ 終點站
「缺漏」→ 路徑上的空位
「五年累積」→ 越來越完整的資料庫／檔案櫃

這會比普通 icon + card 有意思很多。

---

**第三個是「超現實比例」。**

我特別注意到你傳的 Excel 人物、資料夾海、蜂巢人物。

人物非常小，資訊物件非常大。

這會產生一種：

> **「人正在資料裡面行走」**

的感覺。

這個概念我甚至覺得可以成為你們首頁第一屏。

### 「五年，我們會留下多少東西？」

一個小小的學生站在畫面中央。

周圍是巨大化的：

```text
📁 課程
📁 作品
📁 證照
📁 活動
📁 競賽
📁 專題
📁 實習
```

遠處是一大堆散亂資料。

學生開始往前走。

Scroll ↓

這些東西慢慢被整理、分類、串起來。

最後形成：

**「我的五年學習歷程」**

這樣不用寫一大段「本系統旨在解決……」，訪客光看動畫就懂你們為什麼做這套系統。

---

**第四個是「編輯設計感」。**

你那張藍線時間軸跟資料夾 Tab 的圖很關鍵。

它們不像網站模板。

比較像：

> 雜誌 × 海報 × 資訊設計 × 網頁

所以我現在反而不建議學生端全部都是：

```text
╭────────╮ ╭────────╮ ╭────────╮
│ CARD   │ │ CARD   │ │ CARD   │
╰────────╯ ╰────────╯ ╰────────╯
```

我們可以大量利用：

**超大年份、細線、Tab、編號、局部照片、裁切圖片、手繪路線、不同方向文字、留白。**

例如：

```text
04
專四
────────────────────────────

                 ╭─────── PROJECT 07
     ╭──────╮    │ 資管科智慧學習歷程
     │證照  │────●
     ╰──────╯       \
                     \
          2026        ● 實習
                       \
                        ◎ YOU ARE HERE
```

這就開始有作品味了。

---

**第五個，也是我最喜歡的：資料夾 Tab。**

你傳的第 6 張其實可以直接影響學生端。

因為「學習歷程」本來就是在整理資料。

所以學生的五年甚至可以設計成：

```text
╭──── 專五 ────────────────────────────╮
│ ╭──── 專四 ───────────────────────╮ │
│ │ ╭──── 專三 ──────────────────╮ │ │
│ │ │ ╭──── 專二 ─────────────╮ │ │ │
│ │ │ │ ╭──── 專一 ────────╮ │ │ │ │
│ │ │ │ │                  │ │ │ │ │
│ │ │ │ │    我的第一年     │ │ │ │ │
```

點「專四」。

整個專四資料夾抽出來。

裡面：

**COURSE / PROJECT / CERTIFICATE / ACTIVITY / REFLECTION**

再點 PROJECT。

作品像紙張一張張抽出來。

這種互動其實很符合「檔案／歷程」這個主題，而不是為藝術而藝術。
